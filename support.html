Traceless Support

Traceless scans and cleans local Mac caches, developer data, AI model files and app traces.

Before scanning

Choose your personal folder when prompted. Traceless only scans folders that macOS and you have authorized.

Language

Open Traceless → Settings → Language, choose Follow System, English or 简体中文, then reopen the app.

Questions or feedback

Please open an issue on our GitHub support page. Do not include private files, passwords, API keys or personal data in an issue.
